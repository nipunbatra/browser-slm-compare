How the comparison works

Each run uses the pinned checkpoint’s bundled chat template and one user message. Generation is greedy, with a limit of 64 new tokens. The export includes the rendered prompt, generated token IDs and raw decoded text with special tokens.

A WebGPU result reports whether the inference worker observed GPU compute dispatches. ONNX Runtime’s WebGPU provider can also place some operators on the CPU. WASM is a separate, opt-in CPU mode using the same files for SmolLM2. The pinned WASM runtime lacks an operator needed by Gemma and Liquid. WebGPU support depends on browser, hardware and memory. Physical iPhone Safari has yet to be verified.
